QuickCorrect.cs (316줄)

글을 쓰는 동안 자동으로 고쳐 주는 규칙을 다루는 파일이에요. 도구 > 빠른 교정 내용 창이 여기에 있어요.
창에는 탭이 세 개 있어요. [빠른 교정 사용자 사전]은 틀린 말을 맞는 말로 바꾸는 목록이고, [입력 자동 명령 사용자 사전]은 입력한 말을 내용으로 바꾸는 목록(순서를 바꿀 수 있어요)이에요. [입력 자동 서식]은 따옴표, 대시, 말줄임표, 괄호, 글머리 기호, 번호, 날짜 같은 자동 변환을 켜고 끄는 곳이에요. 고치는 즉시 받은 설정 객체에 반영하고 그 객체를 저장해요.
사전은 탭으로 나눈 글 파일(한 줄에 "틀린 말[탭]맞는 말")로 불러오고 저장할 수 있어요. 틀린 말에는 띄어쓰기를 넣을 수 없어요.
WordPair는 사전의 한 줄이고, QuickCorrect.IsBoundary는 낱말이 끝났는지(띄어쓰기, 엔터, 문장부호를 쳤는지) 알려 주는 함수예요.

1	네임스페이스
3~8	WordPair: 사전 한 줄(틀린 말, 맞는 말)
10~11	QuickCorrect 설명과 클래스 선언
13~14	IsBoundary: 낱말이 끝나는 글자인지
15	QuickCorrect 클래스 끝
17~18	PairEditDialog 설명과 클래스 선언(사전 한 줄 넣고 고치는 창)
20~22	입력칸과 FromText, ToText
24~64	생성자: 입력칸과 버튼, 틀린 말이 비었거나 띄어쓰기가 있으면 안내
65	PairEditDialog 클래스 끝
68~72	QuickCorrectDialog 설명과 클래스 선언
74~75	필드: 설정, 강조색
77~100	생성자: 탭 세 개와 [닫기] 만들기
102~277	BuildDictTab: 사전 탭(검색칸, 목록, 추가·고치기·지우기·위아래·불러오기·저장 버튼, 비었을 때 안내)
279~315	BuildFormatTab: 입력 자동 서식 탭(자동으로 바꾸기, 자동으로 서식 설정 체크 칸들)
316	QuickCorrectDialog 클래스 끝
