TxtWebBook.cs (215줄)

txt를 epub처럼 WebView2로 보여 주려고, 글을 작은 HTML 문서 여러 개로 나눠 임시 폴더에 써 두는 "가상 epub"이에요. 메모장 같은 TextBox로는 줄 간격, 문단 간격, 다단 페이지를 못 주기 때문에 epub과 같은 웹 화면(페이지 넘김, 테마, 글꼴, 낭독, 이미지 확대)을 같이 쓰려는 거예요. 챕터를 기본 단위로 하고, 4만 자가 넘는 챕터는 한도 안쪽의 마지막 줄바꿈에서 다시 잘라요(두 칸짜리 글자의 가운데에서는 끊지 않아요). 각 줄은 <p data-o="전체 글 기준 시작 위치">로 쓰고 공백까지 그대로 살려서, 문단 안 글자 위치가 원본 글자 위치와 1:1로 맞아요. 그래서 읽던 자리와 찾기를 원본 위치로 주고받아요. 자동 줄바꿈을 켜면 문장 단위로 줄을 나눠요. 만들 때마다 새 임시 폴더를 쓰고(두 창이 같은 글을 열어도 서로 지우지 않게), 쓰다가 실패하면 쓰다 만 본문 복사본을 지워요.
