칸 안에 단위(pt, %)가 같이 보이는 숫자 입력칸이에요: "10.0      pt ⇅". 값을 직접 써도 되고 화살표로 올리고 내려도 돼요. 글자 속 숫자만 읽어서 값으로 쓰고 범위 안으로 맞춰요. 문단 서식 창에서 써요.

1~2	도구함
4	네임스페이스
6~7	설명과 클래스 선언
9~10	Unit: 단위 글자
12~13	RefreshText: 단위를 바꾼 뒤 칸 글자를 다시 쓰기
15~19	UpdateEditText: 숫자와 단위를 한 칸에 보이게
21~31	ValidateEditText: 입력한 글에서 숫자를 읽어 범위 안의 값으로
32	클래스 끝
