EpubWebGuard.cs (50줄)

epub 웹 화면이 "이 컴퓨터 안의 주소만" 쓰게 묶어요. epub은 인터넷에서 받은 남의 웹 문서(XHTML과 스크립트)라서 열기만 해도 외부 서버에 접속하거나(읽는 사람의 IP가 알려지고 추적 그림이 불려 옴), 새 창을 띄우거나, 다른 사이트로 넘어갈 수 있어요. 그래서 모든 요청을 지나가게 걸어 로컬이 아니면 빈 403 응답을 주고, 다른 주소로 가는 이동과 새 창은 막아요. 책 안의 글, 그림, 스타일은 모두 풀어 둔 폴더(file://)에 있어서 정상 epub에는 영향이 없어요. 막은 기록은 처음 20번까지만 남겨요.
