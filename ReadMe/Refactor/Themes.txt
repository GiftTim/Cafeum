5. Themes.cs 

앱의 색 테마를 정의하고 창과 메뉴에 색을 입히는 파일이에요.
테마 7개(카페 라이트, 카페 다크, 라이트, 세피아, 눈 편한 초록, 다크, 블랙)의 배경·글자·링크 색을 담고, 두 색을 섞는 도구, 컨트롤을 안쪽까지 칠하는 함수, 어두운 제목 막대와 스크롤바를 켜는 윈도우 호출, 메뉴를 테마 색으로 그리는 렌더러가 들어 있어요.
"라이트" 테마만 윈도우 기본 모양을 그대로 써요(SystemLook).

1~4	도구함
6~18	ReaderTheme: 테마 한 개의 모양. 
20~32	Themes.All: 테마 7개. 
34	Find: 이름으로 테마 찾기(없으면 첫 번째)
36	ToCss: 색을 웹용 글자로
38~39	Blend: 두 색 섞기
41~43	CreateRenderer: SystemLook이면 윈도우 기본 모양에 넘침 버튼만 새로 그리는 렌더러, 아니면 테마 렌더러
45~51	시스템 함수 2개 불러오기(제목 막대, 스크롤바 테마)
53~58	ApplyChrome: 창에 테마 입히기
60~95	Recolor: 컨트롤 색칠(재귀). 
97~98	SendMessage 불러오기
100~114	SetScrollbarTheme: 어두운 스크롤바
116~125	SetDarkTitleBar: 어두운 제목 막대
126	Themes 끝
128~161	ThemeColorTable: 메뉴 색 표
163~185	OverflowButtonPainter: 넘침 버튼(테두리 상자 안의 아래로 향한 겹꺾쇠, 펼침 창이 열려 있는 동안은 눌린 모양) 그리기
187~192	SystemLookRenderer: 라이트(윈도우 기본 모양) 테마용, 넘침 버튼만 새 모양
194~236	ThemeRenderer: 메뉴를 실제로 그리는 부분(글자, 화살표, 넘침 버튼, 체크 표시)
