JsonFile.cs (156줄)

설정, 서재 기록, 일정, 뽀모도로, 작품 폴더의 .cafeum.json과 메모 같은 JSON 파일을 안전하게 읽고 쓰는 공용 도구예요.
쓸 때는 먼저 글자로 만들어 보고(여기서 실패하면 기존 파일은 그대로예요), 이번 실행에서 처음 저장하는 파일이면 지금 파일을 .bak으로 복사해 두고, 임시 파일(.tmp)에 쓴 다음 본 파일과 바꿔요. 숨김 파일은 덮어쓰기가 막힐 수 있어서 잠깐 풀었다가 다시 숨겨요.
읽을 때는 파일이 없으면(처음 실행) 조용히 null을 돌려줘요. 내용이 깨졌으면 깨진 파일을 .corrupt로 옮겨 두고 .bak에서 되살려 본 파일 자리에 다시 놓아요. 다른 프로그램이 잡고 있어서 못 읽는 것은 깨진 게 아니므로 세 번까지 다시 읽어 보고, 그래도 안 되면 파일은 그대로 두고 null을 돌려줘요. 이렇게 읽지 못한 파일은 다음에 읽기에 성공할 때까지 저장하지 않아요(기본값으로 시작한 쪽이 멀쩡한 파일을 덮어쓰지 않도록).
실패는 모두 cafeum.log에 한 줄 남기고, 저장 실패는 화면에도 알려요(같은 파일은 1분에 한 번만).
