ZoomBubble.cs (104줄)

글자 크기를 바꿀 때 툴바의 보기 버튼 밑에 잠깐 뜨는 작은 상자예요. "12pt (109%)" 같은 값과 [−] [+] [초기화] 버튼이 있고, 2.2초 뒤에 저절로 사라지되 마우스가 상자 위에 있으면 남아 있어요. 숫자가 바뀌어도 상자 폭이 들썩이지 않게 가장 넓은 글자 기준으로 폭을 잡고, 둥근 모서리 바깥은 창 모양을 잘라서 뒤의 본문이 그대로 비쳐요. 색은 라이브러리 팔레트를 따라요.
