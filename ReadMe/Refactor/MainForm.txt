MainForm.cs (764줄, partial class MainForm의 본체)

소설·만화·PDF·한글 문서를 읽는 화면의 본체예요.
MainForm.*.cs 여러 파일이 한 클래스를 나눠 쓰는데, 이 파일은 화면 부품 선언, 생성자(메뉴, 터치, 찾기), PDF 열기, 종류별 화면 전환(SetContentMode)을 맡아요. 파일 열기·저장은 Viewer/MainForm.Files.cs, 읽기 방식 전환은 Viewer/MainForm.ReadingMode.cs로 옮겼어요.
txt는 읽을 때 epub과 같은 웹 화면으로 보여주고, 고칠 때만 텍스트 상자로 바꿔요. 종류마다 화면 자리가 따로 있고 한 번에 하나만 보여요.
