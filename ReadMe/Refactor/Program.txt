Program

앱이 켜지는 곳이에요.
앱을 하나만 켜지게 하고, 이미 켜져 있으면 새로 켜지 않고 받은 파일·폴더 경로를 켜져 있는 앱에 넘긴 뒤 끝내요. 같은 컴퓨터 안의 파이프라는 통로를 써요.
켜진 쪽은 통로를 계속 듣고 있다가 넘어온 경로를 AppShared에 전달해요.
곳곳에서 처리하지 못한 오류를 한곳에서 받아 cafeum.log에 기록하는 일도 해요.

6	Program 클래스 선언. partial이라 ShotTest.cs와 나눠 가져요.
8	파이프 이름(Cafeum.SingleInstance.Pipe)
