SidebarBrand.cs (167줄)

왼쪽 옆 막대에 쓰는 두 부품이 들어 있어요.
SidebarBrand는 옆 막대 맨 위의 로고 줄이에요: [앱 아이콘] Cafeum(필기체)과 부제, 아래에 접기 버튼(‹ / ›). 로고를 누르면 BrandClicked(작품 목록으로)이고, 접기 버튼을 누르면 CollapseClicked예요. 좁게 접혀 있으면 아이콘과 펼치기 버튼만 그려요. 필기체 글꼴(Segoe Script, 없으면 기본 글꼴 굵게)은 TitleFont가 정해요.
SidebarNavItem은 옆 막대의 메뉴 한 줄이에요: [아이콘] 글자. 고른 줄은 옅은 바탕이고, 접혀 있으면 아이콘만 보이며 글자는 툴팁으로 보여 줘요.
