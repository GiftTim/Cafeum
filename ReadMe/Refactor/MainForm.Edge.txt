MainForm.Edge.cs (296줄, MainForm의 일부)

책의 끝(마지막 페이지에서 더 넘김)이나 처음(첫 페이지에서 더 되돌림)에 닿았을 때의 처리예요.
같은 폴더에 다음·이전 파일이 있으면 보기 메뉴의 설정(여기서 멈추기, 안내 띄우기, 자동으로 열기)대로 움직이고, 폴더의 마지막·첫 파일이면 설정창의 "처음·마지막 파일에서"(아무것도 안 하기, 물어보기, 다시 처음으로, 다음·이전 폴더로)대로 움직여요.
"옆 파일"은 같은 폴더에서 확장자가 같은 파일을 이름의 자연 순서로 세어 정해요. ] 키는 다음 파일, [ 키는 이전 파일이에요.
만화 zip과 소설의 페이지 방식(txt, epub)이 같이 쓰고, 스크롤 방식과 pdf는 여기로 오지 않아요.
