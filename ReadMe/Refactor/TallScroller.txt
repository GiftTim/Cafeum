TallScroller.cs (196줄)

집필 화면에서 상세 정보(머리)와 글 상자를 한 장으로 이어서 같이 스크롤시키는 패널이에요. 글 상자는 스스로 스크롤하지 않도록 글 길이만큼 키워 두고, 이 패널이 머리와 글 상자를 통째로 밀어요. 자동 스크롤 대신 세로 스크롤바 하나를 직접 써서 가로 스크롤바는 생길 수가 없어요.
글이 바뀌면 높이를 다시 재고(스크롤바가 필요한지는 글 높이에, 글 높이는 폭에 달려 있어서 두 번 맞춰 봐요) 커서가 보이게 스크롤해요.
