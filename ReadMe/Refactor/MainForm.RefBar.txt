MainForm.RefBar.cs (292줄, MainForm의 일부)

참고 자료 문서(작품의 "참고 자료" 폴더 안 파일, 또는 탐색기 "Cafeum으로 보기"로 연 PIP 창의 문서)의 서식창을 맡는 파일이에요.
문서 종류(txt, epub, 만화, pdf)와 상관없이 같은 줄을 쓰고, 종류에 안 맞는 버튼은 감춰요.
줄의 구성: [파일 추가] [네비게이션 바] [용지 편집] [한쪽/두쪽 보기] [순서·나누기] [보기 모드] [읽기 방식] [낭독/슬라이드] [줄바꿈·줄간격] [PIP] [항상 위] [잠금 모드] [몰입] [설정]. 항목 순서와 켜고 끄기는 설정창의 "참고자료 서식창"에서 정해요.
[잠금 모드]는 읽다가 실수로 글을 고치거나 화면을 눌러 쪽이 넘어가는 걸 막아요(실제 막는 일은 MainForm.Lock.cs).

1	이름 칸
3~8	설명과 partial class 선언
10~12	RefBarDefault: 서식창 항목의 기본 순서(sep로 시작하는 건 구분선)
14~20	ToolbarRefOrder: 설정에서 정한 순서(저장된 순서에 없는 항목은 기본 자리 뒤에 붙임)
22~40	RefBarLabel: 설정창 목록에 보이는 항목 이름
42~46	AddReferenceRequested, PipRequested: [파일 추가], [PIP] 단추를 눌렀다는 알림
48~50	InPip: PIP 작은 창 안의 문서인가(그 안에서는 [PIP], [파일 추가], [항상 위]를 숨김)
52~59	필드: 버튼들, 아이콘 색, 구분선 목록, 항목 → 키 목록, 잠금 상태
61~74	EnsureRefItems: 참고 자료 서식창에만 쓰는 버튼들을 처음 한 번 만들기
76~92	ToggleLockMode: 잠금 모드 켜고 끄기(켜면 고치는 중이던 글을 저장하고 읽기로, 터치 넘김 끔)
94	marginDrop: 만화의 용지 편집 펼침 부품
96~107	ShowMarginDrop: 만화의 [용지 편집] — 여백 칸을 버튼 바로 밑에 직접 펼치기
109~119	SyncRefBar: 읽기 서식창을 참고 자료용이나 보통(epub·만화)으로 바꿔 두기
121~158	ApplyRefBarLayout: 참고 자료 서식창 항목을 늘어놓기
160~194	SyncRefBarKind: 지금 문서 종류에 안 맞는 버튼은 감추고, 설정에서 뺀 항목도 감추기
195~225	RefreshOrderIcon: 순서·나누기 아이콘 다시 그리기
227~240	ShowImageOrderMenu: 읽는 순서와 한 장을 둘로 나누기 메뉴(만화)
242~291	RefreshPipIcon: PIP 아이콘(큰 네모 안의 ↘ 화살표와 작은 네모) 그리기
