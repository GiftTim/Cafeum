MenuGuard.cs (82줄)

팝업 메뉴가 열려 있는 동안 메뉴 밖을 한 번 누르면 닫아 주는 도우미예요. WinForms 기본 동작은 웹 화면(WebView) 위처럼 다른 창이 클릭을 받으면 메뉴를 닫지 못하는 경우가 있어서, 마우스 단추가 새로 눌리는 순간을 30ms마다 직접 지켜봐요. 메뉴를 연 그 클릭이 아직 눌려 있으면 닫지 않고, 메뉴가 닫히면 감시도 끝내서 처리기가 쌓이지 않아요. 시험용 마우스 흉내는 Scripts/Test/MenuGuard.Test.cs에 있고 배포판에서는 항상 null이에요.
