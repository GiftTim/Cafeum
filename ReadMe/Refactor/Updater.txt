Updater.cs 

GitHub 릴리스에서 새 버전을 찾아 내려받고 설치하는 파일이에요.
사용자가 업데이트 메뉴를 눌렀을 때만 동작해요. 최신 릴리스의 버전을 지금 버전과 비교해서 새 버전이면 설치 프로그램(Setup.exe)을 임시 폴더에 받고, SHA-256을 확인한 뒤 조용히 설치하고 앱을 닫아요.
받는 주소는 코드에 정해 둔 저장소의 github.com(https)만 쓰고, 프로그램을 켤 때 임시 폴더에 남은 옛 설치 파일도 지워요.

1~6	도구함
8~14	설명과 클래스 선언
16~19	RepoSlug(업데이트 받을 저장소), busy 깃발
21~34	CleanupOldInstallers: 옛 설치 파일 청소. 
36~39 	버전을 항상 네 자리로 맞춰 비교(Normalize, Current)
41~49	인터넷 연결 도구(HttpClient)
51~56 	Release 정보에 Sha256 추가, IsGitHubUrl(주소 검증)
58~90	CheckAsync: 확인 → 가져오기 → 새 버전 안내 → 설치 진행
92	Format: 버전을 보기 좋게
94~115	FetchLatestAsync: GitHub에 최신 릴리스 묻기.
117~180	DownloadAndInstallAsync: 내려받고 설치
└ 119		파일 이름만 쓰기(GetFileName)
└ 120~130	진행창
└ 133~148	내려받기
└ 149		1MB 미만이면 실패
└ 150~157	SHA-256 확인(맞지 않으면 실패, 값이 없으면 기록만 남기고 진행)
└ 159~166	실패 처리
└ 168~178	설치 프로그램 실행
└ 179		앱 종료
