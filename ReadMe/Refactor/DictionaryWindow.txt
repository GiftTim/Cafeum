DictionaryWindow.cs (758줄)

사전 창이에요. 작업하던 화면 위에 따로 떠 있는 작은 창이고, 왼쪽 아이콘 막대의 [사전]으로 켜고 꺼요. 위 탭으로 국어사전, 한영 사전, 영한 사전을 오가며 단어를 찾아요. 뜻은 위키낱말사전에서 가져오고, 한 번 찾은 단어는 이 컴퓨터에 저장돼서(DictionaryCache) 인터넷이 끊겨도 다시 볼 수 있어요. 오른쪽 끝의 [단어장] 탭은 내가 넣어 둔 단어를 그룹별로 보여 주고(WordBookView), 단어장에서 단어를 찾으면 그 단어가 어느 그룹에 있는지 바로 보여요. 뜻 아래의 [단어장에 넣기]로 단어를 모으고, 이미 들어 있으면 어느 그룹에 있는지 적어 줘요. 머리 줄을 끌면 창이 움직이고, 두 번 누르거나 ⌄를 누르면 머리 줄만 남게 접혀요. 가장자리를 끌면 크기를 바꾸고, 놓은 자리와 크기, 탭은 설정(DictWindow)에 기억해요. 찾기는 차례 번호(gen)로 관리해서 탭을 바꾸거나 새로 찾으면 늦게 도착한 옛 결과는 그리지 않아요. 파일 아래쪽에는 이 창을 이루는 작은 부품이 있어요: 머리 줄과 탭(DictChrome), 검색칸(DictSearchField), 글자 단추(TextButton), [+ Group] 단추(GroupButton). 직접 그리는 부품은 글꼴을 FontCache에 만들어 두고 다시 써요.
