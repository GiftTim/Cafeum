MainForm.QuickFix.cs (202줄, MainForm의 일부)

글을 치는 동안의 자동 교정을 맡는 파일이에요.
친 글자 자리에서 바로 바꾸는 입력 자동 서식(…, —, 따옴표, 괄호 짝)과, 방금 친 낱말이 끝났을 때 적용하는 입력 자동 명령·빠른 교정(틀린 말 → 맞는 말 사전), 영어 서수와 날짜 정리, 엔터를 쳤을 때 글머리 기호·번호 이어 붙이기가 있어요.
IME로 한글을 입력하는 도중에는 건드리지 않고, 글자가 다 들어간 뒤에 살펴요. ⋯ 메뉴에 [도구 > 빠른 교정 내용… / 글 한 번에 다듬기…]를 넣어요. 각 기능은 설정에서 켜고 끌 수 있고, 고치는 중인 txt에서만 동작해요.
