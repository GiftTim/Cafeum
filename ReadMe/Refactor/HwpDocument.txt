HwpDocument.cs (360줄)

한글 문서(.hwp, .hwpx)에서 본문 글만 뽑아 내요. 커피뷰어는 이 글을 txt와 같은 읽기 화면으로 보여 주고, 고치는 일은 한컴 한글에 맡겨요. 한컴오피스가 없어도 읽을 수 있게 형식을 직접 풀어요. HWPX는 zip 안의 Contents/section0.xml 같은 파일에서 문단(p)마다 한 줄씩, 글자와 탭과 줄바꿈만 살려요. HWP 5.x는 OLE 복합 문서(CFB) 안의 BodyText/Section0 같은 스트림(보통 deflate 압축)에서 문단 글 레코드만 읽어요. 표 안의 글은 문단으로 이어서 나오고, 그림, 수식, 글상자 같은 개체는 건너뛰어요. 암호가 걸렸거나 배포용 문서는 읽을 수 없고, 3.0 이하의 아주 옛 문서도 못 읽어요. 남의 파일일 수 있고 형식을 직접 풀기 때문에, 파일 크기, 풀린 크기, 문단 수, 복합 문서의 섹터 사슬에 한도와 순환 검사를 두어서 일부러 망가뜨린 파일이 앱을 멈추거나 메모리를 다 쓰지 못하게 해요.
