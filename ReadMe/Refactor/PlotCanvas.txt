PlotCanvas.cs (1476줄)

플롯 캔버스를 만드는 파일이에요. 에피소드, 위키 문서, 메모를 넓은 판 위에 놓고 선으로 이어서 작품의 흐름과 관계를 정리하는 화면이에요.
파일 트리의 에피소드 그룹 줄 오른쪽 [캔버스] 아이콘을 누르면 그 그룹의 캔버스가 문서 칸에 열려요. 그룹마다 하나씩이고 작품폴더\canvas\그룹이름.canvas에 저장돼요.
저장 형식은 JSON Canvas(옵시디언의 .canvas와 같은 구조)예요. 에피소드와 위키 노드는 원본을 복사하지 않고 작품 폴더 기준 경로로 가리키기만 하고(두 번 누르면 옆 칸에 원본이 열려요), 메모 노드는 글을 직접 담아요. 작품 폴더 밖을 가리키는 노드는 없는 문서로 보고 열지도 읽지도 않아요.
파일을 읽고 쓰는 일은 JsonFile이 맡아요. 내용이 깨졌으면 .corrupt로 옮기고 .bak에서 되살리고, 다른 프로그램이 잡고 있어서 못 읽은 파일은 덮어쓰지 않아요. 고치면 0.6초 뒤에 저장하고, 저장하지 못하면 다음 변경 때 다시 시도해요.
CanvasNode, CanvasEdge, CanvasDoc은 파일에 담기는 값이고, CanvasStore는 읽기, 쓰기, 경로 계산과 캔버스 설정(정렬 가이드, 클릭으로 드래그)이에요. PlotCanvasView는 캔버스 한 장을 그리고 다루는 판(노드 옮기기와 크기 바꾸기, 연결선 잇기, 화면 이동과 확대, 선택, 복사와 붙여넣기, 되돌리기, 내보내기와 가져오기)이고, PlotCanvasPage는 그 위에 도구 줄을 얹은 문서 칸 화면이에요.
