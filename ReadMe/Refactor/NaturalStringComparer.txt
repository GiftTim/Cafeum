NaturalStringComparer.cs (44줄)

"2.jpg"가 "10.jpg"보다 앞에 오도록, 사전순이 아니라 숫자 크기 순으로 이름을 비교해요. 만화 zip 안 파일 이름이 1.jpg, 2.jpg, ... 10.jpg 식이라 꼭 필요해요. 숫자 덩어리는 앞의 0을 떼고 길이와 값으로 비교하고, 정수부가 같을 때 한쪽만 소수부(.5)가 이어지면 그쪽이 뒤라서 "8권, 8.5권, 9권" 순이 돼요. 숫자가 아닌 글자는 글자 값 그대로(대소문자 구분) 비교해요.
