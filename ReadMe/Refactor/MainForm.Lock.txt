MainForm.Lock.cs (105줄, MainForm의 일부)

참고 자료 서식창의 [잠금 모드]를 맡는 파일이에요.
잠금을 켜면 문서 화면이 완전히 잠겨요. 페이지 터치, 쪽 넘김, 스크롤, 클릭, 키 이동이 모두 안 먹고, 화면을 누르거나 휠을 돌리거나 이동 키를 누르면 "현재 잠금모드 상태입니다"가 떠요.
웹 화면(WebView2)은 입력을 앱의 메시지 루프를 거치지 않고 받기 때문에, 문서 화면 위에 거의 투명한 작은 창(LockOverlay)을 덮어서 마우스와 터치를 대신 받아요.

1	이름 칸
3~8	설명과 partial class 선언
10~12	덮개 창, 덮개 위치를 맞추는 타이머(0.15초), 마지막으로 안내를 띄운 시각
14~39	SetLockUi: 잠금을 켜거나 풀 때 화면 입력 막기, 슬라이드쇼 멈춤, 덮개 창 켜고 끄기, 버튼 상태 맞추기
41~52	SyncLockOverlay: 덮개 창을 문서 화면 자리에 맞추고, 문서가 안 보이는 동안(다른 탭, 최소화)은 숨기기
54~60	LockToast: "현재 잠금모드 상태입니다"를 1.2초에 한 번만 띄우기
62~73	BlockedByLock: 잠금 중에 쪽을 넘기거나 움직이는 키(방향키, PgUp/PgDn, Home/End, Space)를 막고 안내
75~104	LockOverlay: 거의 투명한(불투명도 1%) 작은 창. 눌림과 휠을 받아 알리기만 하고, 활성화되지 않고 작업 표시줄에도 안 뜸
