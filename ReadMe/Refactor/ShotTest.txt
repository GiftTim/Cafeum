ShotTest.cs (172줄)

개발용 화면 점검이에요. Debug 빌드에서만 들어가고 배포용(Release) exe에는 포함되지 않아요. CAFEUM_SHOT 환경 변수에 저장 폴더를 주고 실행하면 스케줄러 화면과 팝업, 뽀모도로, 보기 설정 창 같은 것을 실제로 그려서 PNG로 저장하고, 몇몇 동작(팝업 밖 클릭으로 닫기, 문장 단위 자동 줄바꿈, 안전 저장, 인코딩 고르기, 글 파일 판별, epub 로컬 주소 판별)은 실제 앱 코드를 그대로 불러 결과를 log.txt에 적어요. 마우스는 MenuGuard의 시험용 값으로 흉내만 내요.
