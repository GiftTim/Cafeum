AppSettings.cs

앱 전체의 설정을 담는 상자예요.
테마, 글꼴, 여백, 낭독, 읽기 방식, 도구 막대 순서, 글쓰기 목표처럼 설정창에서 고르는 값을 칸으로 나열하고, 
설정 파일(settings.json)에서 읽고 쓰는 일과 데이터 폴더의 위치를 정해요.
계산이나 화면은 없고 설정 값을 보관하는 일만 해요. 파일이 없거나 읽을 수 없으면 기본값으로 시작해요.

1~5	도구함
7~29	선택지 목록 2개: EdgeFileAction(파일 끝 동작), NovelReadingMode(읽기 방식)
31~36	클래스 선언과 설명
37~87	읽기 화면 설정(테마, 글꼴, 여백, 줄 간격, 낭독, 읽기 방식 등). 
89~101	txt 자동 줄바꿈, 챕터 나누기 설정
103~108	탐색 막대 설정
110~112	ToolbarLayoutVersion, ToolbarLayoutCurrent: 서식창 설정이 어느 배치 기준으로 저장됐는지
114~125	도구 막대(숨길 버튼, 순서)
127~154	마지막 볼트, 정렬, 아이콘 막대
155~156	처음엔 사이드바에 없는 위젯(특수문자 등)을 [위젯 모음]에서 "사이드바에 넣기"로 켠 것들.
159~160	타입라이터: 글을 쓰고 있는 줄이 늘 화면 가운데에 오도록 부드럽게 스크롤한다.
161~162	빠른 따옴표: 따옴표를 치면 한 쌍이 만들어지고, 따옴표 앞에서 Enter를 치면 따옴표를 넘어 다음 줄로 간다.
164~189	글쓰기 목표, 자동 저장 시간, 빠른 교정 사전
190~213	글자 수 세기, 자동 입력(말줄임표, 따옴표 등)
214~215	글자 수 위젯을 글쓰기 화면 오른쪽 아래에 띄울지(상태 줄의 글자 수 칸을 누르면 다시 켜진다).
215~227	북마크, 서재 설정(지금은 안 쓰는 옛 설정)
228~229	묶음을 처음부터 접힌 채로 보여줄지(펼쳐서 보던 것만 펼침).
230~231	묶음 안 책 제목을 머리글보다 안쪽으로 들여쓰는 폭(px, 화면 배율 100% 기준).
233~237	설정 · 기록 파일을 두는 폴더(%LOCALAPPDATA%\Cafeum). CAFEUM_DATA_DIR 환경 변수가 있으면 그 폴더를 쓴다(설치본의 실제 설정을 건드리지 않고 시험
239~250	ResolveDataDir (메서드)
248	설정 파일 경로(settings.json)
250~254	JSON 모양(들여쓰기, 한글 그대로)
260~266	Load: 설정 읽기(없거나 깨졌으면 기본값)와 서식창 설정 옮기기
268~286	MigrateToolbar: 서식창 배치가 바뀌었을 때 이미 저장된 설정을 새 배치에 맞추기(없어진 fnav 빼기, 맨 앞 구분선 감추기, 새 구분선 sepF6 감추기)
