AppSettings.cs

앱 전체의 설정을 담는 상자예요.
테마, 글꼴, 여백, 낭독, 읽기 방식, 도구 막대 순서, 글쓰기 목표처럼 설정창에서 고르는 값을 칸으로 나열하고, 
설정 파일(settings.json)에서 읽고 쓰는 일과 데이터 폴더의 위치를 정해요.
계산이나 화면은 없고 설정 값을 보관하는 일만 해요. 파일이 없거나 읽을 수 없으면 기본값으로 시작해요.

1~5	도구함
7~29	선택지 목록 2개: EdgeFileAction(파일 끝 동작), NovelReadingMode(읽기 방식)
31~36	클래스 선언과 설명
37~87	읽기 화면 설정(테마, 글꼴, 여백, 줄 간격, 낭독, 읽기 방식 등). 
89~101	txt 자동 줄바꿈, 챕터 나누기 설정
103~108	탐색 막대 설정
110~121	도구 막대(숨길 버튼, 순서)
123~134	마지막 볼트, 정렬, 아이콘 막대
136~151	글쓰기 목표, 자동 저장 시간, 빠른 교정 사전
152~173	글자 수 세기, 자동 입력(말줄임표, 따옴표 등)
175~187	북마크, 서재 설정(지금은 안 쓰는 옛 설정)
189~206 	DataDir: 데이터 폴더(%LOCALAPPDATA%\Cafeum), 환경변수 CAFEUM_DATA_DIR, 옛 CafeumOffice 폴더 자동 이전
208	설정 파일 경로(settings.json)
210~214	JSON 모양(들여쓰기, 한글 그대로)
216~219 	Load/Save: 이제 JsonFile이 읽기·쓰기·백업을 맡아요
