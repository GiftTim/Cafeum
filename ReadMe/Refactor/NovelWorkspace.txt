NovelWorkspace.cs (1384줄)

작품 안의 작업 화면을 만드는 파일이에요. 작품에 들어가면 늘 이 화면이 열리고, 왼쪽부터 [아이콘 막대] | [파일 트리 칸] | [문서 칸] (| [옆 문서 칸]) 순서로 놓여요.
문서 칸 하나에는 문서가 하나만 열려요(탭이 없어요). 다만 참고 자료는 한 칸 안에서 탭으로 여러 개 열 수 있고, PIP로 내보내면 그 탭 자리에 안내 글만 남겨 둬요. 파일 트리에서 누르면 지금 고른 칸에, Ctrl+누르면 옆 칸에 나눠 열고, 파일 트리에서 끌어다 놓으면 창 스냅처럼 놓일 자리를 미리 보여 줘요.
칸이 비어 있으면 작품 화면(NovelOverview)이 보이고, 이때는 왼쪽 아이콘 막대 대신 위쪽 머리 줄이 나와요. 작품에 들어오면 늘 소설 메인에서 시작하고, 열어 둔 칸은 기억하지 않아요.
몰입 모드(F11)에서는 아이콘 막대, 파일 트리, 칸 머리를 숨기고, 끝낼 때 파일 트리를 들어가기 전 상태로 되돌려요.
뽀모도로 타이머 위젯도 여기서 띄우고 자리를 잡아요. 소설 메인에서는 숨기고, 문서에 들어가면 다시 나타나요.
파일 안에는 NovelWorkspace 말고도 아이콘 막대(WorkspaceRail), 칸 하나의 틀(PaneFrame), 문서 칸(DocPane), 소설 메인 머리 줄(MainHeaderBar), 스냅 미리보기(SnapPreview)가 함께 들어 있어요.
