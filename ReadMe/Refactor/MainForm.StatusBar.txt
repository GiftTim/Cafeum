화면 아래 상태 줄 오른쪽 끝에 메모장 같은 칸들을 보여 주는 파일이에요: [줄 N, 열 M] [화면 배율 %] [Windows (CRLF)] [UTF-8] 같은 값과 글자 수(공백 포함·제외).
txt를 보고 있을 때만 나타나요. TextBox에는 커서 이동 알림이 없어서 0.2초마다 살피고, 커서 위치·글 길이·배율이 바뀌었을 때만 다시 세요. 줄과 열은 줄바꿈으로 접힌 화면 줄이 아니라 글 안의 실제 줄 기준이고, 페이지 방식이면 전체 글 기준 위치로 세요.
