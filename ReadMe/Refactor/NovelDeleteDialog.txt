NovelDeleteDialog.cs (81줄)

작품을 지울 때 뜨는 확인 창이에요. 작품 이름을 그대로 적어야만 [소설 삭제하기]가 눌려서 실수로 지우는 걸 막아요. 이름이 맞으면 버튼이 진한 빨강이 되고, 아니면 옅은 빨강이고 눌러도 아무 일이 없어요.
창을 연 쪽(작품 화면)이 확인 뒤에 폴더를 휴지통으로 보내요.

1	네임스페이스
3~6	설명과 클래스 선언
8~10	필드: 입력칸, 삭제 버튼, 작품 이름
12~69	생성자: 경고 제목, 안내 두 줄, 입력칸, 삭제 버튼 만들기
71	Matches: 입력한 이름이 맞는지
73~80	SyncButton: 이름이 맞는지에 따라 버튼 색 바꾸기
81	클래스 끝
