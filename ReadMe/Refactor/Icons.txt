여러 화면이 같이 쓰는 그림 아이콘이에요(UI 폴더). 글꼴 글리프로 낼 수 없는 모양을 직접 그려요. 사이드바(아이콘 막대)의 타입라이터 · 위젯 · 메모 · 빠른 따옴표 아이콘, 위젯 패널의 같은 아이콘, 위젯 목록의 체크 표시가 여기를 불러요. 색과 화면 배율(u)은 부르는 쪽이 넘겨요. 예전에는 사이드바 클래스(WorkspaceRail) 안에 있어서 위젯 패널이 사이드바를 거쳐 가져다 썼는데, 그림은 UI 폴더 한곳에서 부르도록 옮겼어요.
