LibraryChrome.cs (455줄)

서재 화면(책 목록 창)을 이루는 작은 부품들을 한곳에 모은 파일이에요. 모양은 전부 코드로 그려서 윈도우 버전이나 글꼴에 상관없이 같게 보이고, 색은 LibraryPalette 한 벌에서 와요. LibraryPalette는 읽기 화면 테마 하나에서 바탕, 옆 막대, 머리 막대, 카드, 강조색을 뽑아서 어떤 테마든 같은 짜임새(머리 막대가 가장 진하고 옆 막대, 본문 순)가 되게 해요. 부품은 둥근 납작 버튼(PillButton), 검색칸(SearchField), 영문 머리말과 큰 제목(TitleBlock), 가로 스크롤바 없는 트리(NoHScrollTreeView), 이름과 숫자 한 줄(StatRow), 맨 위 머리 막대(LibraryHeader), 선 그림 아이콘 버튼(IconButton)이에요. 직접 만든 그림이나 말풍선은 부품이 닫힐 때 같이 해제해요.
