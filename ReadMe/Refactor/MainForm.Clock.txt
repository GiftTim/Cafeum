MainForm.Clock.cs (92줄)

MainForm의 일부로, 글쓰기 화면의 시계 위젯(ClockWidget)을 붙이고 다루는 파일이에요. 위젯 모음(톱니바퀴, 사이드바에 넣기·빼기)이나 사이드바 시계 아이콘으로 켜고 끄고, 놓은 자리를 창 오른쪽 끝과 위쪽 기준으로 설정에 기억해요. 접거나 펼치면 크기를 바꾸되 위쪽과 오른쪽 끝은 그대로 둬요. 시계 위치(도시, 시간대)는 위젯 모음의 톱니바퀴에서 고르고 ApplyClockPlace로 위젯에 반영해요.
