MainForm.Hwp.cs (160줄, MainForm의 일부)

한글 문서(.hwp, .hwpx)를 읽고 고치는 부분이에요.
읽기는 HwpDocument가 문서에서 본문 글만 뽑아 txt와 같은 웹 화면으로 보여줘요. 한컴오피스가 없어도 읽을 수 있어요.
수정하기는 설치된 한컴 한글에 그 파일을 넘겨요(표·그림·글자 모양을 지킨 채 고치려면 한글에서 고쳐야 해서요).
한글에서 저장하면 파일이 바뀐 것을 알아채고 1.5초 조용해진 뒤 읽던 자리 그대로 다시 읽어 와요.

1~2	도구함(프로세스 실행, 레지스트리)
4	이름 칸
6~12	설명과 partial class 선언
13~16	hwpSource(지금 보는 글이 한글에서 뽑은 것), 파일 감시자, 감시 중인 경로, 다시 읽기 타이머
18~47	LoadHwpFile: 한글 문서를 백그라운드에서 읽어 글만 뽑기(진행률, 취소)
49~70	EditHwpInHancom: 한컴 한글로 이 파일을 열고 저장을 지켜보기 시작
72~97	FindHancomExe: 레지스트리에서 한글 실행 파일 찾기(확장자 → ProgID → 열기 명령, Hwp로 시작하는 실행 파일만)
99~116	StartHwpWatch: 파일 변경·생성·이름 바꿈을 지켜보다가 조용해지면 한 번만 다시 읽기
118~124	StopHwpWatch: 지켜보기 끝
126~138	InitHwp: 다시 읽기 타이머 연결, 창을 닫을 때 정리
140~159	ReloadHwpAfterSave: 한글이 아직 파일을 쓰는 중이면 1.5초 뒤 한 번 더 시도(최대 3번)
