MainForm.Format.cs (209줄, MainForm의 일부)

"서식" 메뉴(윈도우 메모장처럼)와 글자 크기 확대·축소를 맡는 파일이에요.
자동 줄바꿈과 글꼴 대화상자를 만들고, Ctrl+휠이나 Ctrl+±, Ctrl+0으로 글자 크기를 1pt씩 바꿔요(8~48pt). 휠을 빨리 돌려도 매번 큰 글을 다시 배치하지 않도록 목표 크기만 쌓아 두었다가 잠깐 멈추면 한 번만 반영해요.
글자 크기가 바뀔 때 보기 버튼 밑에 "12pt (109%)" 같은 작은 표시를 잠깐 띄우고, 사용자 지정 글자 크기와 만화 보기 배율을 숫자로 입력하는 창도 여기 있어요.

1	이름 칸
3~4	설명과 partial class 선언
6	wordWrapMenuItem: 자동 줄바꿈 메뉴 항목
8~22	BuildFormatMenu: 서식 메뉴(자동 줄바꿈, 글꼴…) 만들기. 페이지 방식에서는 줄바꿈을 항상 켜 두고 바꿀 수 없게 함
24~30	ToggleWordWrap: 줄바꿈 켜고 끄기(열린 파일이 있으면 그 파일에만 기억)
32~50	ApplyEditorWrap: 설정과 읽기 방식에 맞춰 본문 상자의 줄바꿈과 스크롤바를 정하고, 선택 위치와 보던 자리를 되돌리기
52	구분 주석(글자 크기 확대·축소)
54~59	기본 글자 크기(11pt), 확대 타이머, 대기 중인 목표 크기, 글자 크기를 바꿀 수 있는 화면(txt, epub)
61~65	ZoomBy: 1pt씩 키우거나 줄이기(목표 크기만 쌓아 둠)
67	ZoomReset: 기본 크기로
69~74	ZoomTo: 목표 크기를 8~48pt로 정하고 타이머 다시 재기
76~82	ApplyPendingZoom: 잠깐 멈추면 한 번만 실제로 반영(이 파일에만 기억)
84	구분 주석(글자 크기 표시)
86	zoomBubble: 보기 버튼 밑에 뜨는 표시
88~114	ShowZoomBubble: "12pt (109%) − + 초기화"를 잠깐 띄우기
116~149	AskCustomFontSize: 보기 > 글자 크기 > 사용자 지정(8~48pt 직접 입력)
151~184	AskCustomImagePercent: 보기 > 보기 모드 > 사용자 지정(원본 대비 10~500% 직접 입력)
186~208	ChooseFont: 글꼴 대화상자(설정창과 같은 설정값 사용)
