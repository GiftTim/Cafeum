NovelFiles.cs (56줄)

작품 폴더 안에 두는 숨김 파일들의 이름과, 예전 이름(.caffeum...)에서 새 이름(.cafeum...)으로 옮기는 일을 맡아요. 예전 버전이 만든 작품 폴더를 처음 열면 한 번 이름을 바꿔 주고, 새 이름이 이미 있으면 그쪽을 쓰고 옛 파일은 건드리지 않아요. 이름을 바꾸지 못하면(다른 프로그램이 쓰는 중 등) 옛 이름 파일을 그대로 읽고 써서 작품 데이터가 안 보이게 되는 일이 없어요. 확인은 폴더마다 이번 실행에서 한 번만 해요.

1	네임스페이스
3~8	설명과 NovelFiles 선언
10~17	숨김 파일과 폴더 이름: 작품 정보, 메모, 메모 그룹, 서식 보관 폴더
19~22	새 이름과 옛 이름의 머리말, 전체 이름 목록, 확인한 폴더 기억, 잠금
24~31	PathOf: 숨김 파일의 경로(옛 이름만 남았으면 옛 경로)
33	Exists
35~54	Migrate: 옛 이름을 새 이름으로 옮기기
56	클래스 끝
