도구 > 빠른 교정 창이에요. 글에 흔한 자잘한 흐트러짐을 한 번에 고쳐요: 줄 끝 공백, 겹친 띄어쓰기, 여러 개 이어진 빈 줄, 말줄임표 통일(.. ... → …), -- 를 —로, 곧은 큰따옴표를 둥근 따옴표로.
