GroupOverflow.cs (209줄)

서식 줄(ToolStrip)이 좁아졌을 때의 넘침 처리를 맡아요. WinForms 기본 동작은 오른쪽 끝부터 항목을 하나씩 잘라 넘침 버튼 안에 세로로 늘어놓는데, 여기서는 구분선(|) 사이를 한 묶음으로 봐요. 묶음이 통째로 들어갈 때만 줄에 두고, 일부만 들어가면 그 묶음은 뒤의 묶음까지 모두 가려요. 가려진 묶음의 구분선도 같이 가려서 줄 끝에 구분선만 남지 않아요. 오른쪽 넘침 버튼(⌄⌄)을 누르면 기본 목록 대신 가려진 묶음을 묶음마다 한 줄로, 구분선을 사이에 두고 아래로 쌓은 창을 띄워요. 항목은 복사하지 않고 그대로 옮겨 담았다가 닫을 때 원래 번호 자리로 돌려놓아서 항목의 동작과 상태가 그대로예요. 펼쳐 둔 동안에도 넘침 버튼이 사라지지 않게 폭이 0인 빈 항목을 줄에 남기고, 버튼은 눌린 모양으로 그려요. 밖을 누르면 닫히는데, 글꼴 목록 같은 펼침 목록이 열려 있는 동안의 클릭은 닫지 않아요. 줄 안의 묶음을 가운데에 놓는 왼쪽 여백 계산(CenteredLeft)도 여기서 해서 서식 줄과 읽기 전용 서식창이 같은 코드를 써요. 서식 줄, 읽기 전용 서식창, 참고 자료 서식창이 이걸 써요.

1~9	설명
10	GroupOverflow 선언
12~23	필드: 줄, 여백과 버튼 폭을 알려 주는 함수, 가려진 묶음, 펼침 창, 옮겨 둔 항목의 원래 번호, 밖 클릭 감시 타이머, 눌린 모양 표식(OpenTag), 넘침 버튼을 남기는 빈 항목
25~37	생성자: 넘침 허용, 기본 넘침 목록 대신 직접 만든 창 띄우기, 크기와 보임 변화에 맞춰 다시 계산
39~40	IsOverflowing: 가려진 항목이 있는지
42~43	IsHidden: 이 항목이 줄에서 빠져 있는지
45	Wid: 항목이 차지하는 폭
47~55	CenteredLeft: 줄 안의 묶음을 가운데에 놓을 왼쪽 여백(가려진 묶음이 있으면 왼쪽 최소 여백)
57~102	Update: 구분선으로 묶음을 나누고 들어가는 묶음만 보이게, 나머지는 넘침으로
104~105	SetMode: 값이 바뀔 때만 넘침 설정을 쓰기
107~112	Toggle: 열려 있으면 닫기, 방금 밖을 눌러 닫혔으면 다시 열지 않기
114~185	Show: 가려진 묶음을 묶음마다 한 줄로 펼친 창 만들기, 밖 클릭 감시
187~188	Close: 펼침 창 닫기
190~208	Restore: 옮겨 둔 항목을 원래 자리로 돌려놓고 정리
209	클래스 끝
