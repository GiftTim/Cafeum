ClockWidget.cs (363줄)

글쓰기 화면의 시계 위젯(플립 시계)이에요. 펼치면 날짜와 [시 : 분 : 초] 숫자판이 공항 안내판(스플릿 플랩)처럼 딸깍 넘어가고, 접으면 머리 줄만 남아요. 숫자판 하나는 위·아래 반쪽으로 그려서, 시간이 흐르면 위쪽 반쪽이 접혀 내려가고 아래쪽 반쪽이 펴져요(DrawFlip). 시계 위치(시간대 아이디와 도시 이름)를 바꿀 수 있고, 못 찾는 시간대면 이 컴퓨터의 시간대를 써요. 파일 아래쪽 ClockPlaces는 도시와 나라 이름과 Windows 시간대 아이디, 현재 UTC 차이("UTC+09:00") 목록이고, ClockZoneDialog는 나라와 도시를 검색해 고르거나 목록에 없으면 이 컴퓨터의 모든 시간대에서 고르는 창이에요.
