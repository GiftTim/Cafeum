SafeFile.cs (93줄)

사용자의 글(원고, 위키, epub)을 파일에 안전하게 쓰는 도구예요. File.WriteAllText는 원본을 바로 비우고 새로 써서 쓰는 도중 앱이 죽거나 전원이 나가면 반쪽 파일이 남아요. 그래서 옆의 임시 파일(.cafeum-tmp)에 끝까지 쓴 다음 원본과 바꿔요. 중간에 멈추거나 실패해도 원본은 그대로예요. 저장 실패 때는 데이터 폴더의 recover 폴더에 사본을 남기는 마지막 안전장치(WriteRescueCopy)가 있고, 옛 한글 인코딩(CP949)에 없는 글자(이모지)가 섞여 '?'로 바뀌는 일을 막으려고 저장 인코딩을 골라 주는 PickEncoding도 있어요.
