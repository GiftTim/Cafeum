AnimationPlayer.cs (121줄)

움직이는 그림(webp, gif)을 재생해요. 프레임을 미리 다 풀어 두지 않고, 백그라운드 스레드에서 다음 프레임을 그때그때 디코딩해서 시간이 되면 UI 스레드로 넘겨요. 넘겨받은 비트맵은 받은 쪽이 해제하고, 넘기지 못한 프레임(멈추라는 신호가 오거나 창이 닫히는 중)은 여기서 버려요. UI가 밀리면 디코딩도 같이 쉬어서 프레임이 쌓이지 않아요. 프레임 간격이 10ms 이하이면 100ms로 봐요. 반복은 파일에 적힌 횟수 대신 설정(무한 반복)을 따라요. 디코딩이나 재생이 실패하면 조용히 멈추고 첫 프레임이 정지 그림으로 남아요.
