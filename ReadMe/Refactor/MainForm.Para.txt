MainForm.Para.cs (149줄, MainForm의 일부)

서식창의 문단 서식(정렬, 여백, 첫 줄, 줄·문단 간격, 줄 나눔 기준)과 글자 서식(진하게, 기울임, 밑줄, 취소선, 글자 색)을 맡는 파일이에요.
고치는 txt에서는 고른 글자(또는 커서 뒤에 칠 글자)에 서식을 입히고, 읽기 화면(웹)에서는 문단 서식을 CSS로 바꿔 붙여요.
txt 파일 자체는 순수한 글로 두고, 입힌 서식은 옆의 숨김 폴더(.cafeum-fmt)에 .rtf 파일로 따로 보관해요. 글을 다시 열 때 글자가 똑같으면 서식을 입히고, 글이 밖에서 바뀌었으면 서식은 버려요.

1	이름 칸
3~4	설명과 partial class 선언
6~13	EditorPara: 글 칸에 걸 문단 서식(문단 서식 창의 값에 서식창의 정렬·줄 간격을 합친 것)
15~34	ShowParagraphDialog: 문단 서식 창 열고 적용
36~56	ParaCss: 읽기 화면(웹)의 글에 붙일 문단 서식 CSS
58	구분 주석(글자 서식)
60~62	formatDirty(서식만 바뀐 상태), CanFormatChars(글자 서식을 적용할 수 있는 상태)
64~72	ApplyCharStyle: 서식 버튼 — 고른 글자에, 안 골랐으면 커서 뒤에 칠 글자에 적용(이미 그 서식이면 해제)
74~82	PickLookColor: 글자 색 고르기
84~92	MarkFormatDirty: 서식만 바뀌었음을 알리고 자동 저장 시계 돌리기
94~104	SyncCharButtons: 서식 버튼이 지금 커서(또는 고른 글자)의 서식대로 눌려 보이게
106	구분 주석(서식 보관)
108~112	FormatSidecarPath: 서식 보관 파일(.cafeum-fmt\이름.rtf) 경로
114~115	HasFormatRegex: 서식이 하나라도 있는지 알아보는 패턴
117~135	SaveFormatSidecar: 서식이 있으면 옆 .rtf에 저장하고, 없으면 있던 서식 파일 지우기
137~148	TryLoadFormatSidecar: 글을 연 직후 보관본이 있고 글자가 똑같으면 서식 입히기
