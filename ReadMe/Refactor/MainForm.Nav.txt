MainForm.Nav.cs (287줄, MainForm의 일부)

읽기 화면 아래의 네비게이션 바(파일 목록, 챕터·이미지 목록, 위치 막대, 이전·다음 쪽)를 MainForm에 이어 주는 파일이에요.
막대는 고정(항상 보임)이거나 고정 안 함(마우스를 본문 아래쪽에 가져가면 나타나고 떠나면 잠시 뒤 숨음)이에요. epub·PDF를 보여 주는 웹 화면은 마우스 이벤트를 WinForms로 넘겨주지 않아서, 타이머로 커서 위치를 직접 살펴요.
txt는 글 위치를 1000칸으로 나눠 막대에 싣고, 만화는 쪽 번호, epub은 챕터와 챕터 안 위치를 싣어요.
회차를 쓰는 중인 화면에는 막대를 숨겨요.

1	이름 칸
3~10	설명과 partial class 선언
12~24	필드: 막대, 메뉴 항목, 타이머(0.15초), 종류, 위치 상수(1000칸), 책 파일 확장자
26~58	InitNavBar: 막대 만들어 연결(파일 목록, 이미지 목록, 이전·다음, 위치 이동, 고정 바꾸기)하고 보기 메뉴에 "네비게이션 바" 넣기
60~63	WritingEpisode(회차를 쓰는 중인가), NavBarOn(막대를 보일 상태인가)
65~86	UpdateNavBarLayout: 고정 여부와 켜짐 여부에 맞춰 막대를 알맞은 자리에 놓기
88~93	PlaceFloatingNavBar: 고정 안 함일 때 본문 아래쪽에 겹쳐 놓기
95~121	OnNavTimer: 위치 갱신, 고정 안 함이면 마우스가 아래쪽에 있을 때 띄우고 700ms 뒤 숨기기
123~146	ConfigureNavBar: 새 파일을 열거나 종류가 바뀌면 버튼 이름(챕터 / 이미지 선택)과 쓸 수 있는 것을 맞추기
148~177	RefreshNavPosition: 위치 막대와 오른쪽 숫자를 지금 보는 곳에 맞추기
179~180	TxtLength: txt 전체 글 길이
182~183	TxtOffset: txt에서 지금 화면 맨 위 글자의 전체 글 기준 위치
185~189	TxtChapterAt: 위치가 속한 챕터 이름
191~200	TxtChapterIndexAt: 위치가 속한 챕터 번호
202~214	OnNavSeek: 막대를 끌어 옮겼을 때 그 위치로 이동
216~223	ShowNavItemList: "챕터" / "이미지 선택" 목록 띄우기
225~229	CurrentListIndex: 목록에서 지금 보는 곳의 번호
231~243	TurnPage: 막대의 ◀ ▶ 와 ← → 키로 이전·다음 쪽(만화는 한 장, 소설은 한 쪽)
245~253	OpenNavNeighbor: 파일 목록에서 바로 앞·뒤 파일 열기(폴더 끝이면 [ ] 키와 같은 처리)
255~261	ShowNavFileList: "파일" 버튼 — 같은 폴더의 책 파일 목록
263~286	NavFolderFiles: 지금 파일이 있는 폴더의 책 파일들(txt, epub, pdf, zip, hwp, hwpx)과 그 안에서의 자리
