EpubBook.cs (168줄)

epub(zip 안에 OPF와 XHTML로 이루어진 전자책) 파일을 열어 챕터 목록을 뽑아요. 통째로 임시 폴더에 풀어 두고 그 안의 XHTML 파일을 WebView2로 그대로 보여 주기 때문에, 이미지와 스타일의 상대 경로가 디스크 파일 경로로 자연스럽게 풀려요. 열기는 META-INF/container.xml에서 OPF 위치를 찾고, OPF의 manifest(파일 id와 경로)와 spine(읽는 순서)으로 챕터를 만들어요. 압축을 풀 때는 폴더 밖으로 나가는 경로(zip slip)를 막고, 항목이 5만 개를 넘거나 풀면 4GB를 넘으면 열지 않으며(적힌 크기를 믿지 않고 실제로 쓴 크기도 세요), 풀어 둔 폴더 밖을 가리키는 manifest 항목은 쓰지 않아요. 열기에 실패하거나 취소하면 풀다 만 폴더를 지워요.
