읽기 화면 맨 아래에 붙는 네비게이션 바예요. [파일] [챕터/이미지] [◀] [위치 막대] [▶] [3 / 20] [고정] 순서로 놓여 있어요. 이 막대는 무엇을 보여주고 무엇을 할지는 모르고, 목록과 위치는 MainForm이 채우며 고른 결과는 이벤트로 돌려줘요. 위치 막대는 누르거나 끌어서 이동하는데, 옮길 때마다 다시 그리는 게 무거운 epub과 txt는 손을 뗄 때 한 번만 이동해요. 목록 창이 떠 있거나 막대를 끄는 중이면 IsBusy가 true라서 자동 숨김이 막대를 치우지 않아요. 끄는 도중 마우스 붙잡기가 풀려도 끄는 중 상태가 남지 않아요.
