MainForm.Features.cs (585줄, MainForm의 일부)

읽기 화면의 부가 기능을 모아 둔 파일이에요. (읽던 자리 기억 · PDF · 낭독 구간은 Viewer 폴더의 MainForm.Resume · Pdf · Tts로 옮겼어요.)
메뉴(최근 파일, 테마, PDF 야간 모드, 자동 재생, 낭독 속도·목소리), 테마와 여백 적용, 설정이 바뀌었을 때의 반영(OnSettingsChanged), 읽던 자리 기억, 파일 끌어놓기, 우클릭 메뉴와 웹 검색, 안내 글(토스트), PDF 열기, 몰입 모드(전체 화면), 단축키, 낭독(TTS)이 들어 있어요.
MainForm.cs가 너무 커져서 새 기능은 이 파일에 모으고 MainForm.cs에는 연결 지점만 남겼어요.
epub 안에서 낭독을 돕는 스크립트(EpubTtsScript)와 윈도우 시스템 호출 몇 개도 여기 있어요.
