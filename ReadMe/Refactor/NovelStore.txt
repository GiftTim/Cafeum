NovelStore.cs (722줄)

작품과 회차의 구조를 다루는 파일이에요. 볼트 바로 아래 폴더 하나가 작품이고, 그 폴더 바로 안의 txt 하나가 회차예요.
회차 순서, 작품 소개, 태그, 메모, 회차 상태·유형·그룹·상세 속성, 참고 자료의 독서상태는 작품 폴더의 숨김 파일 .cafeum.json 하나에 모아 두고(읽고 쓰는 일은 JsonFile이 맡아요), 표지는 .cover.png, 글자 서식은 .cafeum-fmt 폴더의 .rtf에 따로 둬요. 순서 목록에 없는 txt는 이름의 자연 순서로 뒤에 붙어서, 탐색기에서 넣은 파일도 그대로 회차가 돼요.
회차에 관한 값은 파일 이름을 열쇠로 기억해요. 그래서 회차 이름을 바꿀 때는 상태, 유형, 그룹, 속성, 순서, 글자 서식 파일을 새 이름으로 한꺼번에 옮겨 적고, 새 회차를 만들 때는 같은 이름으로 남아 있던 옛 기록을 비워요. 참고 자료의 독서상태와 즐겨찾기도 파일 이름으로 기억하고, 같은 이름의 새 자료를 넣을 때 비워요.
회차 목록을 그릴 때는 회차마다 상태와 유형을 물어보므로, 읽기만 하는 질문은 .cafeum.json의 크기와 고친 시각이 같으면 다시 읽지 않고 담아 둔 값을 써요. 글자 수도 파일 크기와 고친 시각이 같으면 다시 세지 않아요.
이름이 점으로 시작하면 숨김으로 보여 목록에서 사라지고 윈도우 예약어(CON, NUL …)는 파일로 만들 수 없어서, 이런 이름은 쓸 수 없는 이름으로 봐요. 이름을 다듬은 결과가 비면 이름 바꾸기를 거부해요.
맨 뒤의 NovelInputDialog는 작품 만들기, 이름 바꾸기, 소개 고치기에서 이름과 소개를 묻는 작은 창이에요.
