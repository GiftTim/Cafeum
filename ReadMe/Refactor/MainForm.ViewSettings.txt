MainForm.ViewSettings.cs (87줄, MainForm의 일부)

읽기 화면(탐색기 "Cafeum으로 보기"로 연 창, 참고 자료)의 [줄바꿈 · 줄간격] 설정이에요.
예전 [수정하기] 버튼 자리에 들어간 작은 창으로, 문장이 끝나면 줄을 바꿀지(txt만), 줄 간격(%), 문단 간격(px)을 정해요. 읽는 글은 이제 고칠 수 없어요.
확인하면 설정에 저장하고 열려 있는 읽기 화면에 바로 알려서 반영해요.

1	이름 칸
3~7	설명과 partial class 선언
9~24	OpenViewSettings: 창을 열고 확인하면 저장 후 설정이 바뀌었다고 알리기(줄 간격과 문단 간격, 문장 줄바꿈)
27~86	ViewSettingsDialog: 줄바꿈·줄간격 설정 창(체크 칸, 숫자 칸 두 개)
