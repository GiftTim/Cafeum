MainForm.Toolbar.cs (517줄, MainForm의 일부)

메모장식 메뉴 막대(파일 / 편집 / 보기 / 서식 …) 대신 쓰는 얇은 아이콘 툴바예요.
따로 ToolStrip을 만들지 않고 기존 메뉴 막대의 맨 위 항목만 바꿔요. 몰입 모드에서 숨기고 맨 위에 마우스를 대면 다시 띄우는 처리와 테마 색칠이 그대로 통하게 하려는 거예요. 원래 메뉴들은 왼쪽 ☰ 안으로 옮겨서, 수정하기·저장 같은 드문 기능은 거기서 써요.
가운데에는 책 이름과 그 밑 작은 정보 줄(크기, 형식, 진행률)이 놓이고, 오른쪽에는 목차(네비게이션 바), 보기 설정("가" 버튼), 낭독·자동 재생, 몰입, 항상 위, 설정 버튼이 있어요.
머리 막대 버튼의 순서와 켜고 끄기는 설정창에서 정하고, 여기서 그 순서대로 다시 늘어놓아요.

16~24	필드: 아이콘 글꼴, ☰ 메뉴, 낭독 버튼, 목차 버튼, 책 이름 부품
26~30	IconFontName: 윈도우 11이면 Segoe Fluent Icons, 아니면 Segoe MDL2 Assets
