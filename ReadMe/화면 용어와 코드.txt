화면 용어와 코드

사용자(개발자)와 정한 화면 이름이 코드의 어느 클래스에 해당하는지 정리한 표예요. 줄 번호는 2026-11-23 기준이고, 코드가 바뀌면 어긋날 수 있어요(자세한 줄 설명은 ReadMe/Refactor의 파일별 문서를 보세요).
앱의 본체 창은 VaultForm 하나이고, 그 안에서 화면이 둘로 갈려요: 처음 화면(NovelHome)과 작품 안의 작업 화면(NovelWorkspace). 작업 화면 안의 칸(DocPane)이 문서를 담는 자리라서, 회차, 위키, 대분류, 분류, 작품 화면이 모두 같은 칸에 갈아 끼워져요.

─────────────────────────────────────────────
1. 메인 창 — 앱을 켜면 처음 나오는 화면
─────────────────────────────────────────────
· 화면: NovelHome  (Scripts/Novel/NovelHome.cs:12)  — 내 서재, 작품 카드(NovelCard :376), 작품 만들기.
· 왼쪽 옆 막대: VaultSidebar  (Scripts/Window/VaultSidebar.cs:12)  — 볼트 파일 트리, 내 서재.
· 담는 창: VaultForm  (Scripts/Window/VaultForm.cs:9)  — homeMode가 true일 때. ShowHome()(:229)이 이 화면으로 돌아와요.

─────────────────────────────────────────────
2. 소설 메인 창 — 내 서재에서 소설을 골라 나오는 화면
─────────────────────────────────────────────
· 화면: NovelOverview  (Scripts/Novel/EpisodePanel.cs:1934)  — "작품 화면". 제목, 소개, 태그, 표지, [에피소드 · 위키 · 메모 · 참고] 탭, 회차 목록.
  탭 안에 들어 있는 것: 회차 목록(EpisodeList :1348), 위키 보기(WikiSimpleView, WikiMindMapView, WikiViewBar), 메모(MemoView), 참고 자료(RefList :2806).
· 들어가는 길: VaultForm.EnterNovel()(:241)이 workspace(NovelWorkspace)를 보이게 하고, 문서 칸이 비어 있으면 NovelOverview를 보여 줘요. 작품에 들어오면 늘 여기서 시작해요.
· 틀: 이 화면도 NovelWorkspace 안의 문서 칸(DocPane) 하나 속에 떠요(DocPane.ShowOverview, NovelWorkspace.cs:1493, 만들기 :1498).

─────────────────────────────────────────────
3. 에피소드 창 — 소설 메인 창에서 에피소드 → 회차를 눌러 나오는 창
─────────────────────────────────────────────
· 화면: MainForm  (Scripts/Reader/MainForm*.cs, 클래스 선언 MainForm.cs:15)  — 회차 하나 = MainForm 하나(TopLevel=false로 칸 안에 박혀요). txt 편집, 낭독, 위젯이 모두 여기 있어요.
· 담는 칸: DocPane  (Scripts/Novel/NovelWorkspace.cs:1090)의 doc 필드. 칸을 만들 때 new MainForm(path)(:1319쯤).

─────────────────────────────────────────────
4. 문서영역 — 에피소드 창에서 글을 쓰는 곳
─────────────────────────────────────────────
· 글 상자: MainForm 안의 mainEditor(편집용 글 상자, 페이지 모드는 PageLockTextBox — Scripts/Novel/PageLockTextBox.cs).
· 둘레: 글 상자를 둘러싼 서식줄(MainForm.LookBar), 상태 줄(MainForm.StatusBar), 떠 있는 위젯(글자 수, 시계, 특수문자, 맞춤법 — MainForm.Clock/Special/Spell/Writer).
· 아직 정하지 않은 것: 문서영역이 "글 상자만"인지, "글 상자와 그 둘레 전체"인지, 또는 "문서 칸(DocPane) 전체"인지 — 말씀해 주시면 표를 고쳐요.

─────────────────────────────────────────────
5. 사이드 바 — 문서영역 왼쪽의 막대
─────────────────────────────────────────────
· 화면: WorkspaceRail  (Scripts/Novel/NovelWorkspace.cs:697)  — 코드 안에서는 "아이콘 막대" 또는 "사이드바"라고 불러요.
· 항목(Catalog, :700쯤): 서재로 돌아가기, 소설 메인으로, 파일 트리, 메모, 위젯 모음, 사전, 검색 보드, 뽀모도로 타이머, 글자 수 세기, 타입라이터, 빠른 따옴표, (위젯 모음에서 넣는) 특수문자 · 시계 · 맞춤법 검사기, 설정.

7. 위키 창 — 위키를 쓸 수 있는 창
─────────────────────────────────────────────
· 화면: WikiPage  (Scripts/Novel/WikiPage.cs:17)  — 위키 문서 하나. 위에 경로(작품 › 대분류 › 문서 이름), 속성 칸, 본문. 저장은 Wiki.cs(WikiStore).
· 담는 칸: DocPane의 wiki 필드(NovelWorkspace.cs:1281쯤). 경로의 대분류를 누르면 DocPane.OpenGroup("category", 키)를 불러요(:1289).

· 비교: 소설 메인 창 안의 [위키] 탭(WikiSimpleView, WikiMindMapView)은 위키 문서 "목록 보기"예요. 위키 창(문서 하나를 쓰는 창)과는 달라요.

8. 대분류창, 분류창 — 위키 창에서 대분류 / 분류를 눌러 나오는 창
─────────────────────────────────────────────
· 화면: WikiGroupPage  (Scripts/Novel/WikiGroupPage.cs:10)  — 대분류와 분류를 같은 클래스가 보여 줘요. kind가 "category"면 대분류창, "class"면 분류창.
